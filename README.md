# AI Code Generation Cost Paradox

This Python script simulates the cost paradox in AI code generation. It compares two hypothetical LLMs, 'Opus 5.5' (higher cost per token, higher capability) and 'Sonnet 5' (lower cost per token, lower capability), demonstrating how the more advanced model can be cheaper due to requiring fewer tokens for the same task.

## Language

`python`

## How to Run

Run this script using Python: `python cost_paradox.py`.
